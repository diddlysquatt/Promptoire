### 🧠 Core UX additions
- **Drag/Move**: drag the bar or the right‑side handle

- **Ping/Locate**: briefly flash the bar to find it
- **Search**: fuzzy search with optional highlight; Ctrl+F focuses the search box
- **Bulk Edit**: Shift‑click/Shift‑Arrow multi‑select, move/delete in batches
- **Sorting**: Move Up/Down to reorder prompts and categories
- **Undo Delete**: use the toast action to restore recent deletions
- **Backups**: one‑click timestamped JSON backups
- **Stable IDs**: content‑based IDs to keep references consistent

## 🚀 **How to Use the New Features**

### **Changing Themes**
1. Right-click the brain icon → "⚙️ Settings"
2. Go to "🎨 Color Scheme" section
3. Choose from 13 beautiful presets
4. Click "Accept Changes"

Gradients and patterns are no longer configurable.

### **Customizing Category Colors**
1. In Settings → "🎨 Theme Settings"
2. Click the "Category Bar" color button
3. Choose any color you prefer
4. Category headers will use your chosen color
