# Promptoire 2.3.0

Promptoire is a fast, local-first Windows prompt library built around one job: getting the right prompt onto your clipboard with as little friction as possible.

## Highlights

- Configurable global hotkey opens the launcher near your cursor.
- Modifier-free `F1`–`F24` and tilde/backquote hotkeys are supported alongside combinations such as `Alt+C`.
- Compact, titles-only, and comfortable density modes.
- Fast search, favorites, tags, nested categories, and collapsible groups.
- Drag prompts between categories and reorder prompts or categories.
- One-click copy with optional placeholder filling and copy-then-hide behavior.
- Text and image prompts, including negative prompts, model, parameters, and CFG fields.
- Outline-first export for improving or generating prompt libraries with any LLM.
- Flexible outline, Markdown, CSV, and JSON imports with a safe diff preview.
- Local-only storage, atomic saves, timestamped backups, and no telemetry.
- Reliable Settings toggles, Windows startup registration, tray control, and hidden-window recovery through the normal shortcut.
- Optional direct OpenAI improve action with current GPT-5.6 model choices; manual any-LLM copy/paste remains the default portable workflow.

## Install

1. Download `Promptoire-2.3.0-windows-x64.zip`.
2. Verify it with the attached SHA-256 checksum.
3. Extract the folder.
4. Run `Promptoire.exe`.

Promptoire requires Windows 10 or 11 and Microsoft Edge WebView2. The executable is currently unsigned, so Windows may show an **Unknown publisher** SmartScreen notice on first launch.

## Privacy

Your prompt library, settings, backups, and optional API key remain on your computer. Prompt data leaves the app only when you explicitly copy/export it or invoke the optional direct AI-improve action.
