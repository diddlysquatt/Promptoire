## Show HN

**Title:** Show HN: Promptoire – a local-first prompt library one hotkey away

I built Promptoire because my useful prompts were scattered across notes,
chat histories, and text files. It is a small Windows launcher: press a global
hotkey, search or browse nested categories, fill any placeholders, and click
once to copy.

The less obvious feature is the library round trip. Promptoire exports a
human-readable outline with instructions, which can go through any LLM by
copy/paste. The returned outline is parsed into a preview; new prompts and safe
same-path/title updates can be merged without deleting or moving local content.
There is an optional direct OpenAI action, but the normal workflow needs no API
key.

It is built with Python, pywebview, and vanilla HTML/CSS/JS. Data stays in local
JSON files, there is no account or telemetry, and the project is MIT licensed.
I would especially value feedback on the import workflow and Windows launcher
ergonomics.

https://github.com/diddlysquatt/Promptoire
