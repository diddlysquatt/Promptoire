Windows trust

Verify first.
Then run.

Windows may show “Unknown publisher” for an unsigned Promptoire release. That warning reflects missing reputation, not a finding that the app is malicious.

Verify the release

  1. Download only from the official GitHub release.
  2. Keep the ZIP and its published .sha256 file together.
  3. Run the command below and confirm the hashes match exactly.
Get-FileHash .\Promptoire-2.5.0-windows-x64.zip -Algorithm SHA256

Why the warning appears

SmartScreen evaluates the reputation of both a downloaded file and its signing publisher. A new unsigned file starts without either. Self-signing does not help public users, and Microsoft no longer gives EV certificates an automatic first-download bypass.

The realistic paths

Microsoft Store + MSIXBest way to fully avoid download warnings; requires a separate Store package.
Microsoft Artifact SigningVerified publisher for about $9.99/month; initial warnings can still occur.
SignPath FoundationPotentially free for accepted, public, released, actively maintained open-source projects.
Checksummed GitHub releaseHonest and workable for the first community launch, but does not remove SmartScreen.

Promptoire's launch path

Launch transparently with source and checksums, then apply for free SignPath Foundation signing after the project has a public release and verifiable history.
