# Promptoire 2.4.0

Promptoire 2.4.0 sharpens the tiny Windows launcher around its core job: keeping a polished, portable prompt library one hotkey away.

## Highlights

- A compact prompt editor centered on Title, Category, Prompt, Tags, and a roomier Note field.
- Curated dark and light backgrounds, four readable font choices, and visible per-category colors.
- One stateful Expand/Collapse control and a tighter, clearer Edit Library tree.
- A true focus-independent hotkey toggle: one press hides a visible Promptoire even when another app has focus.
- Native minimize and close now hide Promptoire from the taskbar while keeping it available in the Windows notification area.
- Reliable restoration from the tray, hotkey, or desktop shortcut, including after a native minimize.
- A new magical-scroll icon shared by the window, taskbar, notification area, desktop shortcut, About panel, and packaged executable.
- A stronger release gate with a real Windows tray lifecycle probe in addition to the native WebView self-test.

Promptoire remains local-first, lightweight, account-free, telemetry-free, and compatible with outline, Markdown, CSV, and JSON imports.

## Install

1. Download `Promptoire-2.4.0-windows-x64.zip`.
2. Verify it with the attached SHA-256 checksum.
3. Extract the folder somewhere permanent.
4. Run `Promptoire.exe`.

Promptoire requires Windows 10 or 11 and Microsoft Edge WebView2. The executable is currently unsigned, so Windows may show an **Unknown publisher** SmartScreen notice on first launch.

See [Privacy](https://github.com/diddlysquatt/Promptoire/blob/main/docs/PRIVACY.md), [Security](https://github.com/diddlysquatt/Promptoire/blob/main/SECURITY.md), and the full [Changelog](https://github.com/diddlysquatt/Promptoire/blob/main/CHANGELOG.md).
