## Settings IA

Pages and routes:

- General: `/settings/general`
- Appearance: `/settings/appearance`
- Layout: `/settings/layout`
- Hotkeys: `/settings/hotkeys`
- Text & Fonts: `/settings/text-fonts`
- Advanced: `/settings/advanced`
- About: `/settings/about`

Notes:
- Sidebar highlights the active page via `NavLink` active state.
- Deep links to each route are supported by the router.
- Escape key closes Settings (hooked in `SettingsLayout`).
