Privacy

Local-first,
in plain language.

Promptoire keeps your prompt library and settings on your own computer and does not send telemetry.

What stays local

  • Your real library lives in prompts.json.
  • Settings and an optional OpenAI key live in promptoire.config.json.
  • Timestamped backups live in the local backups/ folder.
  • Private runtime files are ignored by git and excluded from public releases.

When data leaves

Only when you explicitly choose an action that requires it:

  • Copy/export puts selected prompts on your clipboard so you can paste them where you choose.
  • Paste from clipboard reads current clipboard text into the import preview.
  • Improve with AI now sends the visible instructions and outline library to OpenAI using your selected model and locally stored key.
  • External support, documentation, and source links open in your browser.

No hidden collection

No account. No telemetry. No analytics. No ads. No cloud database. No background upload of your library.

API keys

The optional OpenAI key is stored locally. Never commit or share promptoire.config.json. The normal copy/paste LLM workflow works without any API key.
