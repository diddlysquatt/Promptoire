# Promptoire 2.5.0

Promptoire 2.5.0 finishes the launcher with two small speed-and-safety improvements.

## Highlights

- A compact **Recent** filter shows copied prompts newest-first, even across large categories.
- Recent prompts remain searchable and their ordering persists after closing or restarting Promptoire.
- Deleting a prompt is immediate instead of opening a confirmation dialog.
- A small twelve-second **Undo** button restores the deleted prompt to its exact category and position.
- Category deletion still requires confirmation because it can remove an entire nested tree.

Promptoire remains local-first, lightweight, account-free, telemetry-free, and portable.

## Install

1. Download `Promptoire-2.5.0-windows-x64.zip`.
2. Verify it with the attached SHA-256 checksum.
3. Extract the folder somewhere permanent.
4. Run `Promptoire.exe`.

Promptoire requires Windows 10 or 11 and Microsoft Edge WebView2. The executable is currently unsigned, so Windows may show an **Unknown publisher** SmartScreen notice on first launch.

See [Privacy](https://github.com/diddlysquatt/Promptoire/blob/main/docs/PRIVACY.md), [Security](https://github.com/diddlysquatt/Promptoire/blob/main/SECURITY.md), and the full [Changelog](https://github.com/diddlysquatt/Promptoire/blob/main/CHANGELOG.md).
