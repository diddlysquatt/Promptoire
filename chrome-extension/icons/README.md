# Promptoire Extension Icons

This folder should contain the following icon files:

## Required Icons

### icon16.png
- **Size**: 16x16 pixels
- **Format**: PNG with transparency
- **Usage**: Extension toolbar icon (small)
- **Content**: Small brain emoji or "P" letter

### icon48.png
- **Size**: 48x48 pixels  
- **Format**: PNG with transparency
- **Usage**: Extension management page
- **Content**: Brain emoji or Promptoire logo

### icon128.png
- **Size**: 128x128 pixels
- **Format**: PNG with transparency  
- **Usage**: Chrome Web Store listing
- **Content**: High-quality brain emoji or Promptoire logo

## Temporary Solution

If you don't have custom icons, you can:

1. **Use Emoji Icons**: 
   - Create simple icons with brain emoji (🧠) on transparent background
   - Use any image editor like GIMP, Photoshop, or online tools

2. **Use Text Icons**:
   - Create simple icons with "PD" or "P" text
   - Use dark background with white text

3. **Remove Icon References** (temporary):
   - Comment out icon lines in `manifest.json`
   - Extension will use default Chrome icon

## Icon Creation Tools

- **Free**: GIMP, Paint.NET, Canva
- **Online**: Favicon.io, IconMaker, Figma
- **AI**: ChatGPT DALL-E, Midjourney
- **Simple**: Just save brain emoji as PNG files

## Note

The Chrome Extension will work **without custom icons** - Chrome will use default icons. Add custom icons later for a professional look.

For now, the extension is fully functional without these files!
